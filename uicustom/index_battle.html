Window Behaviours
Pro

The Pro Edition of this plugin allows you to control whether HUD Windows are closed or stay open when opening the Skill or Item Selection, selecting an Enemy or Ally, and more.

This feature does not work well with Visustella Custom Actor Commands that bypass the Skill menu and jump straight to Actor/Enemy selection. In this case, this plugin cannot control the opening/closing of the game windows.

We suggest not using Visustella Custom Actor Commands if you are having issues with this feature.
